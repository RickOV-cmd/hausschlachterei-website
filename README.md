# Hausschlachterei Straßberger - Website

Moderne, mobile-first Website für die Hausschlachterei Straßberger.

## 🚀 Features

- ✅ Responsive Design (Mobile, Tablet, Desktop)
- ✅ 24/7 Fleischautomat-Seite mit Produktübersicht
- ✅ Vollständige Sortiment-Seite
- ✅ Live-Status für offene Märkte
- ✅ Pop-up für heutige Öffnungszeiten
- ✅ Impressum & Datenschutz
- ✅ Moderne Animationen

## 📝 Wichtig: Platzhalter ersetzen

Bitte ersetze folgende Platzhalter in `src/App.jsx`:

- `[Telefonnummer einfügen]` → Deine Telefonnummer
- `[E-Mail einfügen]` → Deine E-Mail-Adresse  
- `[Name des Inhabers/Geschäftsführers einfügen]` → Inhabername
- `[USt-IdNr. einfügen]` → Deine Umsatzsteuer-ID
- Bildplatzhalter (`📷 Produktbild: ...`) → Echte Produktfotos

## 🛠️ Lokale Entwicklung

```bash
# Abhängigkeiten installieren
npm install

# Entwicklungsserver starten
npm run dev

# Build erstellen
npm run build
```

## 📦 Deployment

Die Website ist optimiert für Vercel:
1. Repository auf GitHub pushen
2. Mit Vercel verbinden
3. Automatisch deployen
